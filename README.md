# Лабораторная работа № 5. Строки, векторы и словари

Хан Кирилл

## Цель

Научиться работать со строкой, вектором, словарём и списком записей.

## Описание

Программа выполняет одну из четырёх частей. A считает вхождения заданного символа в строку. B меняет местами соседние элементы вектора. C прибавляет число к значению заданного ключа в словаре. D составляет заголовки объявлений: названия длиннее 12 символов сокращаются до первых 12 символов с тремя точками.

## Ввод и вывод

Первой строкой вводится A, B, C или D. Для каждой части нужен отдельный запуск. Программа выводит только ответ, без приглашений ко вводу. Текст вводится символами ASCII, регистр учитывается.

В части A следующей строкой вводится текст длиной до 200 символов, затем отдельной строкой один искомый символ. Пробел тоже может быть искомым символом. Пустой текст допускается. Ответ - количество вхождений, в том числе 0.

В части B вводятся количество чисел от 0 до 100 и сами целые числа от -1000 до 1000. Ответ - изменённый вектор в одну строку. Последнее число при нечётном размере остаётся на месте. Для пустого вектора выводится EMPTY.

В части C вводится количество пар от 0 до 100, затем пары "ключ число". Ключ - слово ASCII без пробелов длиной до 40 символов, число - целое от -1000 до 1000. После пар вводятся ключ запроса и целое приращение от -1000 до 1000. Повторный ключ заменяет старое значение. Приращение добавляется после ввода всех пар; для нового ключа исходное значение равно 0. Итоговый словарь выводится по порядку ключей, каждая пара на отдельной строке. Итоговое значение может выходить за диапазон исходных чисел, например 1000 + 1000 = 2000.

В части D вводится количество объявлений от 0 до 100. Затем для каждого объявления вводятся две отдельные строки: название title и раздел section. Названия полей вводить не нужно. Каждое поле должно содержать от 1 до 200 символов ASCII без пробелов по краям. Внутренние пробелы сохраняются. Результат выводится в формате "[раздел] заголовок", в исходном порядке. Повторы сохраняются. Для пустого списка выводится EMPTY. Все записи проверяются до формирования результата.

При неверном выборе части, недопустимом размере, поле или параметре, ошибке чтения программа выводит INVALID и завершает работу. Числа вводятся в формате целых чисел. Вводите только данные выбранной части.

## Примеры

A, ввод:

```text
A
   Cat a12   dog Cat   
a
```

Ответ:

```text
3
```

B, ввод:

```text
B
7
-2 0 3 3 -1 4 0
```

Ответ:

```text
0 -2 3 3 4 -1 0
```

C, ввод:

```text
C
4
beta 2
alpha 5
beta 3
gamma -1
beta 4
```

Ответ:

```text
alpha 5
beta 7
gamma -1
```

D, ввод:

```text
D
2
Used bicycle
Sale
Programming books
Books
```

Ответ:

```text
[Sale] Used bicycle
[Books] Programming ...
```

Пробел перед тремя точками во втором заголовке сохраняется: он входит в первые 12 символов исходного названия.

## Запуск

Создать консольный проект C++ в Visual Studio и добавить Lab5Variant26.cpp. В проекте должна быть одна функция main. Выбрать стандарт C++11 или новее. Запустить без отладки через Ctrl+F5 и ввести данные одной части. Для следующей части запустить программу заново.
